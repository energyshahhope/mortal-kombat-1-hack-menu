## ✨ Features

### ESP
- Frame Data Overlay — view frame data for moves and combos
- Hitbox Viewer — visualize attack and hurtbox hitboxes
- Input Display — show current input sequence
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### Wallhack
- Skin Catalog — browse skins, colors, gear
- Custom Skin Notes — organize player cosmetics
- Solid Hit Spark — improved hit spark visibility

### Aimbot
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-combo
- Jump Buffer Notes — chain complex maneuvers in practice
